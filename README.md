# Nutrition System

Веб-приложение для подбора персонализированного рациона питания на основе анкеты здоровья, аллергий и ИМТ пользователя. Система рассчитывает оптимальный набор блюд на день и формирует отчёт.

## Возможности

-  **Анкета здоровья (2 этапа)** — заболевания ЖКТ, почек, стадия ремиссии; аллергии, непереносимости
- **Расчёт ИМТ** — по росту и весу пользователя
- **Оптимизация рациона** — подбор блюд под целевые КБЖУ с учётом ограничений
- **Обновление блюд** — генерация альтернативного набора
- **Экспорт отчёта** — скачивание плана питания в TXT
- **Личный кабинет** — авторизация, роли (пациент / администратор)
- **Админ-панель** — управление блюдами

## Технологии

**Backend:**
- Python 3.11+
- FastAPI, Uvicorn
- MySQL (PyMySQL)
- Pydantic, python-jose, passlib
- NumPy / SciPy (оптимизация рациона)
- ReportLab, openpyxl, python-docx (генерация отчётов)

**Frontend:**
- React 18 + TypeScript
- Vite
- React Router
- Axios
